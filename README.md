## 🌟 نظرة عامة (Overview)

هذا المستودع يضم الكود المصدري للموقع الشخصي والبورتفوليو التفاعلي للمصمم **أيمن عطا (Ayman Atta)** — مصمم جرافيك وواجهات مستخدم (Mid-Level Graphic & UI/UX Designer).

تم بناء الموقع بأسلوب عصري يركز على الجمع بين **الأداء الفائق (Zero heavy frameworks / 100% Vanilla Web)** و **التجربة البصرية الغامرة (Interactive & Dynamic UI)** مع دعم كامل لتبديل اللغات ونظم الثيمات المتعددة.

## ✨ أبرز المميزات (Key Features)

| الميزة | الوصف التقني والإبداعي |
| :--- | :--- |
| 🌐 **Bilingual Engine (AR / EN)** | نظام تدويل كامل (i18n) بالـ Vanilla JS يدعم التحويل اللحظي للغة مع تفعيل اتجاه `dir="rtl"` والخطوط العربية المخصصة (`Alexandria`). |
| 🎨 **Dynamic Multi-Theme Accent** | محرك لتغيير لون الـ Accent في الوقت الفعلي عبر 4 ألوان زاهية (Emerald, Cyan, Purple, Amber) مع تخزين تفاعلي. |
| 🪟 **Interactive Glassmorphism & Spotlight** | بطاقات زجاجية ثلاثية الأبعاد تتبع حركة المؤشر (Mouse-tracking radial glow) لتعطي إحساساً تفاعلياً عميقاً. |
| 🌌 **HTML5 Canvas Particle Network** | خلفية جزيئات حركية خفيفة جداً ومحسوبة الأداء تتوقف تلقائياً عند مغادرة التبويب لتوفير بطارية الجهاز. |
| 📱 **Responsive Case Studies Lightbox** | نافذة عرض منبثقة (Modal) مع تصنيف ديناميكي للمشاريع (UI/UX, Branding, Social Media, Print) وروابط لدراسات الحالة المباشرة ومشاريع Behance. |
| 📩 **Smart Contact & Interactive Chips** | نموذج تواصل مرن بخيارات تحديد نطاق العمل (Project Scope Tags) مع زر نسخ فوري للبريد الإلكتروني وإشعارات Toast تفاعلية. |

## 🚀 التشغيل السريع (Getting Started)

لا يحتاج المشروع إلى أي عمليات تثبيت معقدة أو Node.js/NPM (Plug & Play):

### 1. استنساخ المستودع (Clone Repo)
```bash
git clone https://github.com/seif4d/ayman.git
cd ayman
```

### 2. التشغيل المحلي (Run Locally)
يمكنك فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيله عبر **Live Server** في VS Code:
```bash
# إذا كان لديك npx مثبت وتريد خادم محلي سريع:
npx serve .
```

## 🎨 التخصيص وإضافة المشاريع (Customization)

### إضافة مشروع جديد:
افتح ملف `index.html` وتوجه إلى مصفوفة `projectsData`:
```javascript
{
  title: "اسم المشروع الجديد",
  cat: "UI/UX Design", // أو Branding, Social Media, Print Design
  img: "رابط صورة العرض",
  link: "رابط بيهانس أو المعاينة",
  internalLink: "projects/your-case-study.html", // (اختياري)
  impact: "أثر المشروع ومخرجاته",
  desc: "وصف موجز للمشروع وأهدافه..."
}
```

### نظام الألوان (Color Theme):
تم اعتماد اللون البنفسجي الأساسي (`#a855f7`) كلون رئيسي للهوية والتصميم (Accent Theme).
